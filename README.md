# Smart-Accountant
A comprehensive, multi-industry accounting platform powered by artificial intelligence, designed to automate financial operations and provide intelligent business insights.

## Beyondwords AI skill (installed)

[Beyondwords](https://github.com/beyondtahir/beyondwords) v1.1.0 (MIT) is installed as a Claude Code project skill at `.claude/skills/beyondwords`.

- **Use it:** in Claude Code, run `/beyondwords` or ask "Use Beyondwords as my publishing team".
- **Runtime setup:** `bash tools/beyondwords/setup.sh` creates `.beyondwords-runtime/` (gitignored) with the hash-pinned dependencies and runs the doctor.
- **Manual doctor:** `.beyondwords-runtime/bin/python .claude/skills/beyondwords/scripts/beyondwords.py doctor`

Keep book projects, credentials and account sessions out of this repo.

Use the auditor agent to review the books with the audit-review skill. If a number was given ($ARGUMENTS), pass it as `--round-threshold`. Don't change the books during the review. Present the findings ordered by severity, each with its evidence and a recommended correcting entry, then ask the user which corrections to record.

TradingView friendly

Paste a Pine Script strategy. Get a backtest.

Inputs, variables, if/else blocks, MACD, Bollinger Bands and strategy.entry calls convert automatically. Anything that can't convert is listed, never silently dropped.

your_strategy.pine
//@version=5
strategy("MACD + BB")
fast = input.int(12)
[m, s, h] = ta.macd(close, fast, 26, 9)
[mid, up, lo] = ta.bb(close, 20, 2)
if ta.crossover(m, s) and close < mid
    strategy.entry("L", strategy.long)
if close > up
    strategy.close("L")
→
FlowDesk rules
Buy when
crossUp(macd(close, p1, 26, 9),
        macdSignal(close, p1, 26, 9))
  and close < bbMiddle(close, 20)

Close long when
close > bbUpper(close, 20, 2)

Market data

Synthetic hourly bars with buy/sell volume split. Example data for trying strategies.

Uses real taker buy volume, so delta is measured, not estimated. Needs internet; works when this file is opened in your own browser.

Columns: time, open, high, low, close, volume, and optionally buy_volume. Works with TradingView, NinjaTrader and Yahoo exports. Without buy volume, delta is estimated from where each bar closes in its range.

Strategy

Risk & costs

Stop 0 = no stop; size then uses Risk % as the share of equity per trade. Target 0 = exit on signal only. Trailing stop follows the best price since entry by that many ATRs and only ever tightens; 0 = off. "Trail starts at" waits until the trade is that many R in profit.
